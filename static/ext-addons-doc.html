一、插件结构

一个插件是一个 JS 文件，导出包含以下字段的对象：

字段必填说明
id是唯一标识，字母数字与短横线，如 my-addon
name是插件显示名称
description是一句话功能说明
category否分类标签，如「自定义」「编辑器」
css否CSS 字符串，自动注入页面 <head>，禁用时自动移除
setup是初始化函数 function(ctx)，返回清理函数
options否子选项数组（自定义插件暂不支持）

二、setup 与 ctx

setup 接收 ctx 对象，提供：

  • ctx.Blockly —— scratch-blocks 的 Blockly 实例（原型、工具函数都在这里）
  • ctx.getWorkspace() —— 返回当前积木工作区实例
  • ctx.addon —— 当前插件自身的定义对象

setup 必须返回一个 清理函数（可 async 返回）。重载页面或禁用插件时会调用它，用于还原原型、移除监听、解绑事件。

三、完整示例

export default {
  id: 'my-first-addon',
  name: '我的第一个插件',
  description: '给带注释的积木加高亮描边',
  category: '自定义',
  // 可选：CSS 自动注入页面 <head>，禁用时自动移除
  css: '.blocklyMainBackground { opacity: 0.98; }',
  // 必填：初始化函数，可写 async；返回清理函数
  setup: function (ctx) {
    const B = ctx.Blockly;
    const ws = ctx.getWorkspace();

    // 1) 覆写原型方法（增强 Blockly）
    const origRender = B.BlockSvg.prototype.renderDraw_;
    B.BlockSvg.prototype.renderDraw_ = function (...args) {
      const r = origRender.call(this, ...args);
      if (this.comment) this.svgPath_.setAttribute('stroke', '#ff8c1a');
      return r;
    };

    // 2) 监听工作区事件
    const onChange = (e) => {
      if (e.isUiEvent) return;
      console.log('积木变化:', e.type);
    };
    ws.addChangeListener(onChange);

    // 3) 返回清理函数：还原一切
    return function cleanup () {
      B.BlockSvg.prototype.renderDraw_ = origRender;
      ws.removeChangeListener(onChange);
    };
  }
};

一、编写插件文件

新建一个 .js 文件，两种写法皆可：

// 写法一：CommonJS
module.exports = {
  id: 'cjs-addon',
  name: 'CJS 插件',
  description: '示例',
  setup: function (ctx) {
    return function cleanup () {};
  }
};
// 写法二：ES Module（推荐）
export default {
  id: 'esm-addon',
  name: 'ESM 插件',
  description: '示例',
  setup: function (ctx) {
    return function cleanup () {};
  }
};

二、导入并启用

  1. 打开「🧩 编辑器插件」面板
  2. 点击蓝色「导入插件」按钮，选择你的 .js 文件
  3. 导入后插件自动出现在列表并立即启用，无需刷新

三、删除与管理

  • 自定义插件项右侧有「删除」按钮，确认后从本地移除
  • 插件保存在浏览器 localStorage（键 extbuilder_custom_addons），刷新后仍在
  • 与内置插件一样，勾选框可随时开关，开关即时生效

四、注意事项

  • 文件内不要使用 import / require 语句（导入器不支持模块解析）
  • id 必须唯一，与已有插件重复会导入失败
  • 自定义插件暂不支持 options 子选项
  • 务必在清理函数里还原你修改过的原型与监听，避免影响其它功能
